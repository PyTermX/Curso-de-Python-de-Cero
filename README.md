## Acerca del curso

Este curso recorre Python paso a paso, desde los fundamentos hasta la automatización de tareas. A medida que avanzan los videos, aquí se publican los ejercicios y ejemplos que se trabajan en cada uno.

El repositorio se actualiza de forma continua: cada nuevo tema trae su carpeta de ejercicios y código de apoyo.

<a id="a-quien-va-dirigido"></a>

## A quién va dirigido

- Personas que quieren aprender a programar y no tienen experiencia previa.
- Personas que quieren optimizar su trabajo a través de la programación.
- Estudiantes que buscan practicar Python con ejercicios guiados.
- Quienes desean automatizar tareas repetitivas con código.
